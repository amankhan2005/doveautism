# Photo originals

Put licensed original photos here, named after their slot (see `src/content/photos.js`),
then run `npm run photos` from `client/`. Originals in this folder are git-ignored;
keep them in the client's own asset storage.

Only use photos that Dove Autism has the right to publish:
- licensed stock photography (keep the license record), or
- photos the organization owns **with signed releases** for every identifiable person.

Never use photos of clients/patients without explicit written permission.
